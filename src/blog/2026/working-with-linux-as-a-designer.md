For most of my career, macOS felt like the default answer for product design. Moving to a tiling Linux setup forced me to question which parts of my workflow genuinely depended on an OS and which ones were just habit.

## What improved right away

Once Figma runs smoothly in the browser alongside a fast local dev environment, the benefits of a minimal, keyboard-first desktop show up immediately:

- **Zero window management friction**: jumping between browser, terminal, code editor, and notes takes a single keystroke.
- **Predictable performance**: static builds, image optimization pipelines, and local servers stay snappy even with dozens of tabs open.
- **Full control over the environment**: themes, fonts, shortcuts, and automation scripts live in plain version-controlled config files.

It is not a setup for everyone, and there is definitely an upfront investment in tweaking small details. Still, shaping your own tools makes daily work feel noticeably calmer and more intentional.
